# @beyond-js/finder

A powerful and flexible file finder utility for Node.js applications.

---

### Modules

The package is composed of the following main modules:

-   [main](./src/modules/main/README.md): The core search functionality, which defines the `Finder` class.
-   [configurable](./src/modules/configurable/README.md): Provides a class (`ConfigurableFinder`) for dynamically
    reconfiguring the search.
-   [collection](./src/modules/collection/README.md): Manages a collection of items found by the `Finder`.
-   [files](./src/modules/files/README.md): A base class for handling file collections efficiently.
